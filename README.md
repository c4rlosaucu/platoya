# PlatoYa
Aplicación web de pedidos de restaurante generada con ayuda de IA (Cursor).

Actores: cliente y cocinero.
Alcance: menú, carrito, dirección, pago con PayPal Sandbox, historial de pedidos y tablero Kanban en tiempo real.
Tecnologías: Next.js, Node.js/Express, Socket.IO, MongoDB Atlas, Railway.

Ejecución local: se completará al terminar el proyecto.
